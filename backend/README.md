
# Marketing Microservices Backend

## Technology Stack
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- MySQL
- Socket.IO

## Services

| Service | Port |
|---|---:|
| API Gateway | 4000 |
| Auth Service | 4001 |
| Campaign Service | 4002 |
| Creative Task Service | 4003 |
| Lead Service | 4004 |
| Conversion Service | 4005 |
| Realtime Service | 4006 |
| Reporting Service | 4007 |

## User Roles
- Admin
- DIGITAL_MARKETING
- DESIGNER
- TELECALLER
- BDM

## Setup
1. Install Node.js LTS.
2. Install project dependencies using npm.
3. Configure environment variables.
4. Configure MySQL and other required services.
5. Run database migrations.
6. Start the required microservices.

## Reporting
The Reporting Service provides role-based dashboards
and reports for Digital Marketing, Designers,
Telecallers, and BDMs.
